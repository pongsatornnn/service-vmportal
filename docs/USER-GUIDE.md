# คู่มือการใช้งาน VM Portal

คู่มือนี้สำหรับผู้ใช้ที่ขอและใช้ VM ในเว็บเปิดอ่านได้ที่เมนู **คู่มือการใช้งาน**

## 1. สมัครและเข้าสู่ระบบ

1. หน้าเข้าสู่ระบบกด **สร้างบัญชีใหม่** กรอกชื่อ นามสกุล ชื่อผู้ใช้ และรหัสผ่าน (อย่างน้อย 12 ตัว มีตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก ตัวเลข และอักขระพิเศษ)
2. รอ Admin อนุมัติบัญชี ระหว่างนี้ยังเข้าสู่ระบบไม่ได้
3. เมื่ออนุมัติแล้ว เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน ไม่ต้องใช้อีเมล

ถ้าไม่ได้ใช้งานจนหมดเวลา ระบบจะให้เข้าสู่ระบบใหม่ ข้อมูลที่ส่งไปแล้วไม่หาย

## 2. ขอสร้าง VM

1. เมนู **ขอสร้าง VM** เลือก **ระบบปฏิบัติการ (Template)** เช่น Ubuntu 24.04
2. ตั้ง **Hostname** (ชื่อเครื่อง) ใช้ a–z, 0–9 และขีดกลาง เช่น `web01`
3. เลือก vCPU, RAM และ Disk ขนาด Disk ต้องไม่น้อยกว่าที่ Template กำหนด
4. ตั้ง **VM username** (ค่าเริ่มต้น `ubuntu`) และเลือก **วิธีเข้า VM**: Password หรือ SSH public key
5. ใส่เหตุผลที่ขอ แล้วกด **ส่งคำขออนุมัติ**

**โควตา:** การ์ดด้านบน (VM, vCPU, RAM, Disk) บอกว่าใช้และจองไปเท่าไร รวมคำขอที่รออนุมัติ ระหว่างกรอก หลอดจะแสดงส่วนของคำขอนี้ ถ้าการ์ดเป็นสีแดงแปลว่าเกินโควตา ปุ่มส่งจะกดไม่ได้ ให้ลดค่าที่ขอ หรือติดต่อผู้ดูแลเพื่อขอเพิ่มโควตา

รหัส VM เป็นคนละรหัสกับรหัส Portal Admin ไม่เห็นรหัสนี้ และระบบลบสำเนาทิ้งหลังตั้งค่าเครื่องเสร็จ จดไว้ให้ดี

## 3. ติดตามคำขอ

เมนู **สถานะคำขอ** แยกเป็นคำขอสร้าง ลบ และรีเซ็ตรหัส ตัวเลขบนเมนูคือรายการที่มีความคืบหน้าใหม่

| สี / สถานะ | ความหมาย |
| --- | --- |
| รออนุมัติ | ส่งคำขอแล้ว รอ Admin ตัดสินใจ |
| กำลังดำเนินการ | อนุมัติแล้ว ระบบกำลังสร้างหรือตั้งค่าเครื่อง ใช้เวลาไม่กี่นาที |
| สำเร็จ / พร้อมใช้งาน (เขียว) | เครื่องพร้อมใช้ที่เมนู เครื่องเสมือน |
| ไม่อนุมัติ / ไม่สำเร็จ (แดง) | กด **ดูรายละเอียด** เพื่ออ่านเหตุผลจาก Admin |
| ต้องตรวจสอบ | ระบบหยุดรอผู้ดูแลตรวจ ไม่ต้องส่งคำขอใหม่ |

ทุกขั้นแสดงเวลาตามเวลาประเทศไทย และชื่อ Admin ที่ตัดสินใจ เมนู **กิจกรรม** แสดงงานที่ระบบทำกับเครื่อง เช่น เปิด ปิด Restart

## 4. ใช้งาน VM

เมนู **เครื่องเสมือน** แสดง VM ของคุณ สถานะ IP และการใช้ CPU / RAM กดปุ่ม **จัดการ** ของแต่ละเครื่อง:

| ปุ่ม | ใช้เมื่อ |
| --- | --- |
| อัปเดต IP | IP ยังไม่ขึ้นหรือเพิ่งเปลี่ยน (เครื่องต้องเปิดอยู่) |
| เปิดเครื่อง / ปิดเครื่อง | ปิดเครื่องแบบปกติ ให้ระบบปฏิบัติการปิดตัวเอง |
| Restart | เริ่มเครื่องใหม่ |
| บังคับปิดเครื่อง | เครื่องค้างจนปิดแบบปกติไม่ได้ งานที่ยังไม่บันทึกอาจหาย |
| Console / Shell ↗ | เปิดหน้าจอเครื่องในแท็บใหม่ ใช้ได้แม้ไม่มี IP ถ้าเบราว์เซอร์บล็อก popup ให้อนุญาตก่อน |

## 5. เข้าเครื่องผ่าน SSH

ใช้ IP จากหน้า เครื่องเสมือน และ VM username ที่ตั้งตอนขอ:

```bash
ssh ubuntu@192.168.1.50
```

ถ้าเลือก SSH public key ให้ใช้ private key คู่กัน เช่น `ssh -i ~/.ssh/id_ed25519 ubuntu@192.168.1.50` ถ้าเลือก Password การเข้า SSH ด้วยรหัสขึ้นกับ Template ที่ผู้ดูแลเตรียมไว้ ถ้าเข้าไม่ได้ให้ใช้ Console แทน

## 6. ลืมรหัส VM

1. เปิดเครื่องไว้ก่อน
2. เครื่องเสมือน → **จัดการ** → **ขอรีเซ็ตรหัส VM** ตั้งรหัสใหม่และใส่เหตุผล
3. รอ Admin อนุมัติ ระบบจะเปลี่ยนรหัสของ VM username เดิมให้ ไม่ต้องรีสตาร์ทเครื่อง

ยกเลิกคำขอที่ยังรออนุมัติได้ในหน้า สถานะคำขอ

## 7. ลบ VM

1. ปิดเครื่องก่อน (ระบบไม่ลบเครื่องที่ยังเปิดอยู่)
2. เครื่องเสมือน → **จัดการ** → **ขอลบ VM** ใส่เหตุผล
3. รอผู้ดูแลอนุมัติ เมื่อลบสำเร็จ โควตาจะคืนให้ขอเครื่องใหม่ได้

การลบเป็นการลบถาวร ข้อมูลในเครื่องกู้คืนไม่ได้ สำรองข้อมูลก่อนขอลบ

## 8. รหัส Portal และบัญชี

- **เปลี่ยนรหัส:** กดชื่อบัญชีมุมขวาบน → **เปลี่ยนรหัสผ่าน Portal** แล้วเข้าสู่ระบบใหม่ทุกอุปกรณ์
- **ลืมรหัส:** ติดต่อผู้ดูแลเพื่อขอโค้ดกู้คืน (ใช้ได้ 15 นาที ครั้งเดียว) แล้วกด **ลืมรหัสผ่าน** ที่หน้าเข้าสู่ระบบ กรอกโค้ดและตั้งรหัสใหม่
- **ออกจากระบบ** ในเมนูบัญชี จะออกจากทุกอุปกรณ์พร้อมกัน

## 9. ปัญหาที่พบบ่อย

| อาการ | ทำอย่างไร |
| --- | --- |
| มุมขวาบนขึ้น ระบบยังไม่พร้อม | ผู้ดูแลกำลังตั้งค่าหรือพักระบบ ส่งคำขอและสั่งงานไม่ได้ชั่วคราว รอแล้วลองใหม่ |
| IP ขึ้น — | รอเครื่องบูตสักครู่ แล้วกด อัปเดต IP |
| Console เปิดไม่ได้ | เครื่องต้องเปิดอยู่ อนุญาต popup และเปิดได้ครั้งละหนึ่งหน้าต่าง ปิดหน้าต่างเก่าก่อน |
| ส่งคำขอไม่ได้ การ์ดเป็นสีแดง | เกินโควตา ลดค่าที่ขอ ลบเครื่องที่ไม่ใช้ หรือขอผู้ดูแลเพิ่มโควตา |
| ปุ่มกดไม่ได้ | เครื่องมีงานอื่นกำลังทำอยู่ หรือมีคำขอที่รออนุมัติ ดูที่ กิจกรรม / สถานะคำขอ |
